# Tour Package Recommendation System

A full-stack Tour Package Recommendation System built using Angular, Django REST Framework, and PostgreSQL.

## Project Overview

This project is designed to help users explore tour destinations, view travel packages, make bookings, and manage tour-related services online.

The system includes three main modules:

- Admin
- Tour Providers
- Customers/Users

The application allows tour providers to manage destinations, transportation, stay details, and packages while customers can browse packages, book tours, make payments, and provide reviews and ratings.

# Features

## Admin Module
- Manage users
- Manage tour providers
- Manage place categories
- View bookings
- Track users
- Manage complaints and replies
- View reviews and ratings

## Tour Provider Module
- Provider registration and login
- Manage destinations
- Manage stay details
- Manage transportation
- Manage tour packages
- View bookings
- Confirm payments
- Reply to enquiries

## Customer Module
- User registration and login
- View destinations and packages
- Book tour packages
- Custom package selection
- Payment system
- Favorites system
- Reviews and ratings
- Enquiry and complaint system
